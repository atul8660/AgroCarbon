# Unified Biomass Estimation Module (Modules 5 & 6)

This constitutes the end-to-end Biomass Estimation Module of the AI-Powered Tree Carbon Assessment System. It takes the species, health, and morphological masks/crops generated by Modules 1-4 and explicitly regresses the Above Ground Biomass (AGB) in kilograms.

## Architecture

This module utilizes a **ConvNeXt Tiny** backbone combined with a deep feature fusion mechanism. The choice of ConvNeXt ensures structural inductive biases are maintained while remaining computationally efficient relative to Vision Transformers. 
It utilizes a **Residual Regression Head** and optimizes on the **Huber Loss** to maintain stability against biomass outliers.

The fusion layer accepts:
1. Deep visual features from the ConvNeXt (Tree shape, texture, visible leaf density)
2. Handcrafted geometric features (Area, Solidity, Extent, Texture metrics calculated from Module 4's masks)
3. Species & Health categorical embeddings (From Module 1 & 2)

## Integration
This module outputs a strict JSON structure containing the regression outcome and forwards it natively to Module 6 for Carbon Conversion logic.

## Usage
*Install requirements:*
`pip install -r requirements.txt`

*Training:*
`python training/train.py --config configs/config.yaml`

*Inference:*
`python inference/predict.py --config configs/config.yaml --image cropped_tree.jpg`
